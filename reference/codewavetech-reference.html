          Contact form

          • 3 steps: project → details → contact, with a progress bar
          • Services, stage, budget (₹ ranges), timeline and channel as tap-to-select options
          • Inline validation for name, email, 10-digit Indian mobile and consent
          • Draft auto-saved in the browser
          • "Get a quote" on any service page pre-selects that service
          • Live site: email + Zoho CRM + WhatsApp alert, reCAPTCHA, reference number

          Tech stack

          Framework
          Next.js 15 (App Router) + TypeScript
          Styling
          Tailwind CSS with this preview's design tokens
          Motion
          Framer Motion
          CMS
          Strapi or Sanity for services, industries, FAQs, blog
          Forms
          Server action → Resend email, Zoho CRM, WhatsApp API
          Hosting
          Vercel or AWS Mumbai, Cloudflare CDN
          Analytics
          GA4, Microsoft Clarity, Search Console

          Shared components

          • TopBar, PillNav with MegaMenu, MobileMenu
          • PageHero with breadcrumbs and KeyFacts panel
          • SectionHeader (eyebrow, title, lead, action link)
          • StatBar, ProductMockup, ComparisonRow
          • ServiceCard, ServicePageTemplate, IndustryCard
          • ProcessStepper, TestimonialCarousel, FAQ
          • ProjectBriefForm, CTABand, Footer

          SEO, speed and accessibility

          • Static pages, Lighthouse target 95+ on mobile
          • Unique title and meta for every page
          • Schema.org Organization, Service, FAQ and Breadcrumb markup
          • WCAG AA contrast, keyboard navigation, reduced motion
          • Hindi version later via next-intl
